---

## 什麼是 KHOS

KHOS 不是一個工具，也不是一個 prompt。  
它是一套**人類與 AI 協作的操作系統** — 把 Ken 的判斷標準、品牌邊界、驗收流程，沉澱成可重複執行的 Agent、Skill、Hook 與 Memory。

目標不是讓 AI 取代 Ken。  
目標是讓 AI 把 Ken 的**現場服務經驗**，變成**可複製的系統化流程**。

---

## 核心原則

1. **AI 是作業單位，不是免費員工**  
   Agent 消耗 token、工具額度、API 成本。KHOS 的設計前提是：每個 Agent 都有明確的任務邊界、成本上限與人工審核點。

2. **80/20 法則**  
   AI 自動產出 80%，Ken 做最後 20% 驗收與定案。  
   尤其是眉眼分析、照片判讀、命理轉譯、價格建議 — 必須保留人工審核。

3. **品牌邊界不可逾越**  
   所有 Agent 輸出必須通過 Brand Guard 閘門：  
   - 不把 KenEyeCue 說成算命  
   - 不使用效果保證語言  
   - 不製造容貌焦慮  
   - 不偏離「眉眼第一印象校準系統」

4. **可追溯**  
   每個 Agent 的輸出都附帶來源、推理鏈與信心標記。  
   資訊不足時標記 ⚠️待確認，不補腦。

## Agent 架構

### Agent 1：Prompt Builder Agent

**用途：** 把 Ken 的語音、截圖、碎片想法，整理成 AI 可執行指令。

**核心規則：**
- 保留 Ken 的真實意圖
- 不要過度擴寫
- 不要擅自更改 KenEyeCue 品牌定位、價格、服務名稱
- 資訊不足時標記 ⚠️待確認
- 輸出格式：
  1. 任務目標
  2. 已知資料
  3. 禁止事項
  4. 輸出格式
  5. 驗收標準

---

### Agent 2：Brand Guard Agent

**用途：** 檢查內容是否違反 KenEyeCue 品牌邊界。

**檢查項目：**
- 是否把 KenEyeCue 說成算命？
- 是否出現改運、保證、一定會、100% 等絕對化語言？
- 是否製造容貌焦慮？
- 是否偏離「眉眼第一印象校準系統」？
- 是否擅自延伸 14 主星眉型定義？
- 是否把象徵分析講成命運預測？

**輸出：** PASS / FAIL + 具體違規行 + 修正建議。

---

### Agent 3：Content Pack Agent

**用途：** 把一個主題轉成 IG / Threads / LINE / FB 可用內容包。

**輸出格式：**
1. Threads 版本
2. IG 輪播 7 張文案
3. IG Caption
4. LINE 私訊承接話術
5. CTA
6. 禁用詞複審

---

### Agent 4：Research Agent

**用途：** 查市場、工具、競品、AI 工作流，不直接替你下結論。

**輸出格式：**
1. 來源
2. 可驗證事實
3. 市場現況
4. 可借鑑處
5. 不適合 KenEyeCue 的地方
6. 建議行動

---

### Agent 5：Acceptance Review Agent

**用途：** 最後驗收，不負責創作，只負責挑錯。

**檢查標準：**
- 這份輸出是否能直接使用？
- 是否有補腦？
- 是否符合 KenEyeCue 定位？
- 是否能降低成交風險？
- 是否有清楚 CTA？
- 是否有未確認資訊標記？
- 是否值得發布？

**評分：** 1-10 分。低於 8 分必須重修一次。

---

## 最小可行工作流

優先建置前 3 個 Agent：

| 優先順序 | Agent | 為什麼先做 |
|:--------:|-------|-----------|
| 1 | Prompt Builder Agent | 解決 Ken 輸入碎片化、語音跳躍、截圖混雜的問題 |
| 2 | Brand Guard Agent | 防止品牌走偏、命理過度、文案失控 |
| 3 | Content Pack Agent | 直接產出社群內容與成交承接 |

---

## 使用方式

在 Hermes 或 Claude Code 中呼叫：

```
請用 KenEyeCue Agent System v1.0 處理以下素材。
啟動流程：
1. 先由 Prompt Builder Agent 整理我的混亂輸入。
2. 再由 Brand Guard Agent 檢查品牌邊界與禁用語。
3. 最後由 Content Pack Agent 產出可發布內容。
4. 結尾由 Acceptance Review Agent 打分，低於 8/10 必須重修一次。

限制：
- 不要把 KenEyeCue 說成算命。
- 不要使用改運、保證、一定會、命中註定、100% 等語言。
- 不要製造容貌焦慮。
- 不要擅自改服務名稱與價格。
- 資訊不足請標記 ⚠️待確認。
- 最終輸出分成 ✅已知事實 / 💡合理推論 / 🎯策略建議 / ⚠️待確認。
```
